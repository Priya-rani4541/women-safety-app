# SheShield 🛡️
### Smart Women Safety & Emergency Response Android Application

SheShield is a modern Android-based women safety application designed to provide instant emergency assistance, real-time location sharing, SOS activation, guardian alerts, and emergency evidence collection during critical situations.

Built using **Kotlin + Firebase + Google Maps**, SheShield focuses on fast response, accessibility, and real-world emergency usability.

---

- Long-press emergency trigger

- Instant emergency workflow execution
